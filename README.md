# VoxAgenda

**VoxAgenda** es una aplicación web en React + TypeScript con tu agente personal interactivo **Aura**, agenda de fechas importantes, lienzo de dibujo artístico por evento, cápsula de recuerdos y alarmas con voz inteligente.

## Características Principales

- **Agente Personal Aura & Briefing por Voz**: Resumen matutino hablado y respuestas interactivas utilizando síntesis de voz en español con 4 personalidades (`Cálida`, `Motivadora`, `Ejecutiva`, `Poética`).
- **Lienzo de Dibujo Interactivo (`DoodleCanvas`)**: Dibuja a mano alzada con pincel multicolor, grosores ajustables, stickers/sellos, borrador y plantillas rápidas por evento, o ilustra tus fechas con fotos reales o bocetos artísticos por IA.
- **Calendario Interactivo y Filtros por Categoría**: Tira de 18 días y filtrado instantáneo por categoría (`Cumpleaños`, `Aniversario`, `Cita Médica`, `Meta Personal`, `Viaje`, `Recuerdo`, `Trabajo`, `Familia`).
- **Cápsula de Recuerdos & Libro Impreso**: Preserva tus eventos especiales con notas emocionales, narración hablada y simulador de impresión bajo demanda (Digital, Tapa Blanda, Pasta Dura).
- **Alarmas Habladas, Club VIP, Catálogo de Regalos y Código QR**: Prueba alarmas en vivo con voz personalizada, explora sugerencias de flores/regalos con cupón de afiliado (`AURA10`) y comparte la app mediante código QR.

## Desarrollo

```bash
npm install
npm run dev
```
